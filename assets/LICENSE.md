# The Wisp character

The artwork in this directory, and the rendered frames in `docs/`, are the
Wisp character design: the flame body, the eyes, the expressions, the
turnaround, the app icon and the palette.

**Copyright (c) 2026 CurlyKojo. All rights reserved.**

They are not covered by the MIT licence in `/LICENSE`, which applies to the
code only. The code is free to reuse; the character is not.

If you want to build on the renderer, swap `assets/` for your own artwork —
`wisp_face/geometry.py` reads the character out of
`assets/source/wisp_geometry.py`, and `WISP_ASSETS` points it somewhere else.
